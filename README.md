# VK-бот для рассылок

Бот сообщества `98171239` собирает явные подписки пользователей и отправляет
рассылки только активным подписчикам. Данные хранятся в SQLite.

## Возможности

- подписка командами `Начать`, `Подписаться`, `/start` или кнопкой;
- отписка командами `Стоп`, `Отписаться`, `/stop` или кнопкой;
- автоматическая деактивация при запрете сообщений сообщества;
- предпросмотр и подтверждение административной рассылки;
- текст и вложенные в команду фотографии/другие VK-вложения;
- отчёт о доставке и число активных подписчиков.

## Настройка сообщества ВК

1. Откройте **Управление → Сообщения** и включите сообщения сообщества.
2. Откройте **Управление → Настройки → Работа с API → Ключи доступа**.
3. Создайте ключ сообщества с правом доступа к сообщениям. Никому его не
   отправляйте и не добавляйте в GitHub.
4. В разделе **Long Poll API** включите Long Poll и выберите актуальную версию.
5. В **Типах событий** включите `Входящие сообщения`, `Разрешение получать
   сообщения` и `Запрет на получение сообщений`.

## Переменные окружения

| Переменная | Значение |
| --- | --- |
| `VK_TOKEN` | Секретный ключ доступа сообщества |
| `VK_GROUP_ID` | `98171239` |
| `VK_ADMIN_IDS` | Числовые VK ID администраторов через запятую |
| `VK_API_VERSION` | По умолчанию `5.199` |

Узнать свой числовой ID можно, написав боту `/id`. Затем добавьте ID в
`VK_ADMIN_IDS` и перезапустите бота.

## Развёртывание на BotHost

1. Создайте бота из этого Git-репозитория и выберите Python.
2. Главный файл: `main.py`.
3. Добавьте перечисленные выше переменные окружения. Если форма BotHost просит
   основной Bot Token, можно указать ключ сообщества там: код также читает
   переменную `BOT_TOKEN`. Предпочтительно всё же использовать `VK_TOKEN`.
4. Выполните деплой и откройте логи. При успехе появится строка
   `Бот запущен для сообщества 98171239`.

На BotHost база создаётся в `/app/data/subscribers.db`, поэтому сохраняется
между обновлениями проекта. Локально она создаётся в папке `data`.

## Административные команды

- `/рассылка Текст сообщения` — создать и показать черновик;
- `/подтвердить` — отправить показанный черновик;
- `/отмена` — удалить черновик;
- `/статистика` — показать количество активных подписчиков;
- `/id` — показать VK ID отправителя.

Чтобы добавить изображение, прикрепите его к сообщению с командой `/рассылка`.

## Локальный запуск

```powershell
python -m pip install -r requirements.txt
$env:VK_TOKEN="секретный ключ"
$env:VK_GROUP_ID="98171239"
$env:VK_ADMIN_IDS="ваш VK ID"
python main.py
```
